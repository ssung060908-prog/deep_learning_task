# Task 1 v2 이후 개선 후보 — 2026-11-20

상태: 조사 및 제한된 후속 실험 제안. 새 학습은 실행하지 않았다. v2는 보존한다.

## 현재 근거와 한계
v2의 3-seed 평균 CV AUROC는 0.80589589, 개발 전용 모델 holdout은 0.81421047이다.
후보 A의 CV 평균은 0.80596579로 약 0.00007 높았다. B는 사전 단순성 기준으로 선택했다.
따라서 v2가 가능한 최고 성능이라는 뜻은 아니다. 0.001은 통계적 유의성 경계가 아니다.
2단계 전처리는 [32]와 단일 seed에 조건부였고, 3단계 구조 비교도 학습 설정을 고정했다.
[64,32]는 구조 비교에서 평균 1위였지만 차이가 작아 이후 세부 튜닝에서 제외했다.
4단계는 학습률·dropout·weight decay·batch를 함께 바꾼 제한된 조합이라 각 요소의 효과를 분리하지 못했다.

## 추천 순서
1. 비신경망 수치 전처리: 각 fold 학습 부분의 분위수로 구간을 정하고 piecewise-linear encoding(PLE)을 만든다.
   8/16 bins 두 후보부터 비교한다. 같은 분위수 경계는 합치고, 상수 열·범위 밖 값·결측 처리를 명시한다.
   특수 코드 -9/-8/-7 표시를 보존한다. 별도 신경망·외부 데이터·앙상블을 사용하지 않는다.
   기존 quantile scaling과 달리 값 하나를 여러 구간 좌표로 나타내므로 기존 quantile 결과만으로 효과를 배제할 수 없다.
   논문에서 MLP에도 수치 임베딩의 효용을 보고했지만 이 HELOC 데이터에서의 개선은 아직 검증하지 않았다.
2. 특수 코드 대체 방식: 현재 중앙값 대체 대신 정규화된 수치 채널을 0으로 마스킹하는 방식을 단독 비교한다.
   의미를 보존하는 코드별 flag는 유지한다. -7을 임의의 실제 기간/연체 횟수로 해석하지 않는다.
   제공 사전은 모든 입력을 numeric으로 표기하므로 이름만 보고 범주형이라고 단정하지 않는다.
3. clipping 영향: 현재 [-8,8] 대신 [-16,16] 한 후보를 비교한다. 극단값의 순위 정보 보존이 도움이 되는지 확인한다.
4. 구조와 학습 조건의 상호작용: [64,32] 및 [128,64]에 lr 0.001/0.003을 조합한 4개 후보.
   전처리는 우선 원래 v2, dropout 0.1, weight decay 0.0001, batch 256, GELU로 고정한다.
   더 큰 모델이 낫다는 주장이 아니라, 기존에 별도 튜닝하지 않은 영역의 제한된 확인이다.

## 제안 실험 예산과 선정 원칙
- 1차: 위 8개 신규 후보 × 기존 고정 5-fold × seed 42 = 최대 40회 CV 학습.
- 동일 조건 v2 결과는 해시·코드·환경이 일치할 때 재사용. 변경된 구현에서는 기준 예측/학습 동등성을 먼저 검증한다.
- 상위 신규 후보 최대 2개에 seed 123/2026을 추가: 최대 20회. 총 최대 60회 신규 CV 학습.
- 초기 200 epochs, patience 25. 상한으로 판단이 끝나지 않은 경우만 기존 방식대로 연장하고 비용을 별도 기록한다.
- 1차에서 개선 신호가 없으면 종료. 추가 seed로 평균 개선이 유지되고 fold별 차이도 검토된 후보만 교체 대상으로 고려한다.
- v2의 0.001 단순성 규칙은 기존 결정으로 보존한다. 후속 실험에서 성능 우선 기준을 바꾸려면 결과를 보기 전에 명시한다.
- 같은 분할을 반복 사용한 CV는 선택 편향이 있다. seed 반복은 데이터 분할 변화의 검증을 대신하지 않는다.
- 추가 분할 검증이 필요하면 개발 데이터 안에서만 v2와 후보를 함께 재평가한다. 그 비용은 위 60회에 포함하지 않는다.
- 이미 관찰한 holdout을 반복 최적화하지 않는다. 이를 새로운 독립 테스트라고 부르지 않는다.
- 후보 확정 전에는 제출 모델을 바꾸지 않고, 더 좋은 후보가 검증되면 별도 v3로 저장한다.

## 우선하지 않는 방향
단순 epoch 증가, 전체 곱/제곱 재탐색(기존 CV 약 0.7906), 최고 seed 골라내기, threshold 조정으로 AUROC 개선 주장.
외부 데이터, Transformer, 다른 신경망 특징 추출, 모델/예측 앙상블은 현재 과제 범위에서 제외한다.
Residual MLP도 문헌상 후보지만 우선 일반 완전연결 DNN에서 확인 가능한 위 실험부터 진행한다.
