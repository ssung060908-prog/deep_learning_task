# 추가 개선 2 — 2층 DNN과 학습률 비교

2026-11-21 완료. 신규 4개 후보 × 고정 5-fold = 20회 CV 학습.
동일 seed 42의 기존 v2를 기준으로 비교했습니다. seed 3개 평균과 혼용하지 않습니다.

| 구조 | 학습률 | 평균 CV AUROC | v2 대비 |
| --- | ---: | ---: | ---: |
| v2 [32] | 0.00168702 | 0.80583254 | — |
| [64, 32] | 0.001 | 0.80561996 | -0.00021258 |
| [64, 32] | 0.003 | 0.80573437 | -0.00009817 |
| [128, 64] | 0.001 | 0.80582224 | -0.00001030 |
| [128, 64] | 0.003 | 0.80516810 | -0.00066444 |

## 판단
최고 후보는 [128,64], lr=0.001로 기존보다 약 0.00001030 낮았습니다.
이 작은 차이를 v2의 통계적 우월성으로 해석하지 않습니다. 이번 비교에서는 개선 근거가 없어 v2를 유지합니다.
실행 전에 정한 규칙(기존 평균을 넘는 상위 최대 2후보만 추가 seed 확인)에 따라 추가 학습은 하지 않았습니다.
여러 seed 또는 다른 학습 설정에서 결과가 바뀔 가능성은 남아 있습니다.

## 비교 조건
Robust 전처리, 파생 비율 및 곱/제곱 미사용, GELU, norm 없음을 유지했습니다.
후보들은 dropout 0.1, weight decay 0.0001, batch 256을 사용하고,
[64,32]/[128,64]와 lr 0.001/0.003을 조합했습니다.
기존 v2와 dropout 및 weight decay도 다르므로 구조 하나의 효과만 검증한 실험은 아닙니다.
개발 6,316행의 고정 5-fold, seed 42+fold번호, 최대 200 epochs, patience 25, CPU 4 threads입니다.
모든 fold가 학습 상한 전에 조기 종료 조건을 충족했습니다.
기존 코드·환경·데이터·분할·조건과 기준 결과 해시를 대조해 결과 재사용을 검증했습니다.

## 보존 및 기록
holdout 평가, 전체 데이터 재학습, 새 가중치 생성, 예측 앙상블은 하지 않았습니다.
v1·v2 배포 파일 해시를 검증해 보존을 확인했습니다. GitHub task1-v2는 그대로입니다.
실험 조건·점수·학습 곡선은 experiments/post_v2_two_layer/에 저장했습니다.
후보 설정: configs/post_v2_two_layer.json.
재현: `python experiment.py search --config configs/post_v2_two_layer.json --output runs/two_layer_repeat --model-seed 42`.
이번 결과는 로컬에 저장했고 GitHub에는 아직 업로드하지 않았습니다.

PLE와 2층 구조 비교는 완료했습니다. 제안했던 결측값 대체·극단값 clipping 비교는 아직 하지 않았습니다.
