# Task 1 — HELOC DNN 결과 및 보고서 원고

2026-11-19. Task 1의 1~6단계 모델 개발 완료. 전체 과제 제출 완료는 아닙니다.

## 데이터와 분할
제공된 7,896행의 신용 이력 23개 변수를 사용했습니다. sample_id는 입력에서 제외했습니다.
목표는 is_at_risk=1일 확률입니다. 기존 고정 분할을 유지해 개발 6,316행, holdout 1,580행으로 나눴습니다.
동일 입력의 중복 행은 같은 그룹에 두고, 개발 데이터의 고정 5-fold로 후보를 비교했습니다.
전처리 통계는 매 fold의 학습 부분에서만 추정했습니다.

## 전처리와 구조
- -9/-8/-7 특수 코드는 결측으로 처리하고 각 코드 및 비유한 값의 표시 변수를 따로 보존했습니다.
- 학습 부분의 중앙값으로 대체하고 Robust scaling 후 [-8,8]로 제한했습니다.
- 23개 수치, 코드/비유한 표시 92개, 행별 결측 비율 1개로 입력은 총 116차원입니다.
- 단일 완전연결 DNN: 116 → 32(GELU, dropout 0.25) → 1(sigmoid). 파라미터 3,777개.
- 파생 비율, 곱/제곱, LayerNorm, class weighting, label smoothing은 사용하지 않았습니다.

## 학습과 선정
AdamW, lr 0.001687023975571048, weight decay 0.000031622776601683795,
batch 256, BCEWithLogitsLoss, gradient norm 제한 5, 매 epoch 학습률 ×0.99를 사용했습니다.
CV에서는 AUROC 개선 >0.00001과 patience 25로 조기 종료했습니다.
전처리·구조·학습 조건을 비교한 뒤 후보 2개를 seed 42/123/2026으로 비교했습니다.
후보 A의 평균 CV AUROC는 0.80596579, B는 0.80589589입니다.
사전 기준(최고 평균과 0.001 이내이면 작은 모델 우선)에 따라 B를 선택했습니다.
이 기준은 통계적 동등성 검정이 아닙니다. B의 seed 평균 표준편차는 0.00020649입니다.
최고 seed를 고르거나 예측을 평균하지 않았습니다.

## 최종 평가와 제출 모델
설정과 seed 42, 37 epochs를 평가 전에 고정했습니다. 37은 B의 15개 seed-fold 최적 epoch의 중앙값입니다.
개발 데이터만으로 37 epochs 학습한 모델의 holdout AUROC는 **0.81421047**입니다.
이전 v1 holdout 0.81394405보다 약 0.00026642 높으나 우월성이 입증된 것은 아닙니다.
holdout은 과거에 이미 관찰됐습니다. 최종 평가 결과로 설정을 바꾸지 않았습니다.
그 후 같은 조건으로 전체 7,896행을 학습해 단일 task1.pt를 만들었습니다.
CV/holdout 점수는 이 전체 학습 모델의 비공개 Test 성능을 뜻하지 않습니다.
