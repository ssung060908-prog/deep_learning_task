# 추가 개선 1 — 수치 변수 구간별 표현 비교

2026-11-20 완료. 신규 2후보 × 5-fold = 10회 CV 학습. 기존 v2의 seed 42 결과 5개는
동일 설정·분할·모델 seed·코드·환경·epoch 상한·patience·CPU threads를 검증한 후 재사용했습니다.
두 신규 후보 모두 최대 200 epochs 안에서 조기 종료됐습니다.

| 방법 | 같은 seed의 5-fold 평균 AUROC | v2 대비 |
| --- | ---: | ---: |
| v2 Robust (기존 결과 재사용) | 0.80583254 | — |
| PLE 8구간 | 0.80308593 | -0.00274661 |
| PLE 16구간 | 0.80286451 | -0.00296804 |

## 판단
두 후보 모두 기존 v2보다 낮아 이번 설정에서는 채택하지 않습니다. v2를 유지합니다.
사전 규칙에 따라 추가 seed 확인은 진행하지 않습니다. 개선 신호가 없는 후보에 추가 학습을 하지 않습니다.
이것은 고정된 [32] GELU·dropout 0.25·학습률 등의 조건에서 seed 42를 비교한 결과입니다.
PLE가 모든 구조·학습 조건에서 나쁘다는 결론은 아닙니다. 반대로 아직 성능 개선의 근거도 없습니다.
현재 모델을 v3로 바꾸지 않았습니다. holdout 평가, 전체 데이터 재학습, 앙상블은 하지 않았습니다.

## 구현과 검증
수치 23개를 Robust scaling 대신 PLE로 변환하고 특수 코드 -9/-8/-7 및 비유한 표시,
행별 결측 비율은 유지했습니다. 각 fold 학습 부분의 관측값으로만 분위수 경계를 추정했습니다.
결측은 학습 중앙값으로 대체합니다. 반복 경계는 합치고, 상수/전체 결측 열은 0 한 채널로 처리합니다.
각 구간은 clip((x-left)/(right-left),0,1)이며 범위 밖 값은 양 끝으로 제한합니다.
추가 신경망 없이 단일 완전연결 DNN을 사용합니다. 입력 차원과 파라미터 수는 fold마다 기록했습니다.
보간값, 범위 밖 값, 중복 경계, 상수·전체 결측, 특수 코드, 열 순서·누락, 빈 입력,
transform이 학습 경계를 바꾸지 않는지를 검사하는 테스트 2개가 통과했습니다.
기존 v1·v2 배포 파일 해시도 그대로인지 확인했습니다.
