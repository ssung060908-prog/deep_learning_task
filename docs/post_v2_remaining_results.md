# 추가 개선 3 — 결측값 및 clipping 비교

2026-11-22 완료. 제출 모델 v2와 과거 결과를 보존했습니다.

## 결측값: 정규화 후 0 대체
현재 RobustScaler의 중심값은 중앙값입니다. 결측을 중앙값으로 대체하고 정규화하면 이미 0입니다.
고정 5-fold의 학습·검증 행 모두에서 기존 표현과 0 마스킹 표현이 정확히 같음을 확인했습니다.
따라서 동일 모델을 다시 학습하지 않았습니다. 특수 코드 -7/-8/-9 및 비유한 값 표시를 보존했습니다.

## 극단값 제한: ±8 → ±16
다른 설정과 분할을 v2 그대로 유지했습니다. seed 42에서 평균 개선이 있어 사전에 정한
seed 123/2026을 추가 확인했습니다. 총 15회 CV 학습이며 비교 기준의 기존 결과는 해시·환경·조건 확인 후 재사용했습니다.

| 모델 seed | ±16 평균 CV AUROC | 같은 seed의 v2 대비 |
| --- | ---: | ---: |
| 42 | 0.80588659 | +0.00005405 |
| 123 | 0.80608978 | -0.00008467 |
| 2026 | 0.80592874 | +0.00024805 |

3-seed 평균: v2 **0.80589589**, ±16 **0.80596837**, 차이 **+0.00007248**.
3개 seed 중 2개에서 높고 1개에서 낮았습니다. 작은 평균 상승은 관찰됐지만 우월성이 입증된 것은 아닙니다.
추가 분할에 대한 검증도 수행하지 않았습니다. 최적 epoch가 최대 상한에 걸린 fold는 없었습니다.

## 결정
±16을 소폭 개선의 잠정 후보로 기록하고 배포 모델은 기존 v2를 유지합니다.
기존 0.001 기준은 실용적 기준이며 통계적 유의성 경계가 아닙니다.
이번 실행 전에 새 가중치로 자동 교체하지 않기로 정했으므로,
holdout 재평가·전체 데이터 재학습·v3 가중치 생성은 하지 않았습니다.
기존 v1·v2 파일의 무결성 검증도 통과했습니다.

## 완료 범위
