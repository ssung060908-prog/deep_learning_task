# 4단계 — 학습 설정 미세 조정

2026-11-19 완료. [32]+GELU, [64]+GELU에 같은 5개 학습 설정 조합을 적용하고 기존 2개 설정을 대조군으로 비교했습니다.
총 12개 설정입니다. 신규 10개 × 5-fold=50회 학습, 기존 2개 × 5-fold=10회 결과 재사용,
상한 추가 확인 2개 × 5-fold=10회 학습을 수행했습니다. 실제 신규 학습은 총 60회입니다.

## 조건 및 상한 확인

Robust 정규화, 파생비율·곱/제곱 미사용, GELU, norm 없음, class weighting·label smoothing 미사용을 고정했습니다.
개발 6,316행, holdout 1,580행, 기존 5-fold와 모델 seed=42를 유지했습니다.
설정 생성 seed=20261119는 후보 조합 생성에만 사용했습니다.
학습률 0.0003~0.003, dropout 0~0.25, weight decay 0.000001~0.001, batch 128/256/512의 제한된 조합입니다.
모든 가능한 조합을 탐색한 것은 아닙니다.

초기 최대 200 epochs, patience=25였습니다. 학습률 0.0003·dropout 0.05·weight decay 0.001·batch 512의 두 구조가
상한에 걸려 동일 조건에서 최대 500 epochs로 다시 확인했습니다. 기존 학습 구간의 AUROC 경로가 재현됨을 확인했습니다.
학습률 감쇠는 총 epoch 상한과 독립적입니다. 늘린 상한에서도 아직 진행 중인 fold 수: 0.
최종 비교에서는 이 두 설정의 500 epoch 상한 결과를 사용하고, 200 epoch 결과도 별도 보존했습니다.
